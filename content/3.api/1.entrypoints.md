# Public entrypoints

- `nuxt-files-sdk`: Nuxt module, server resolver, and native Files SDK exports.
- `nuxt-files-sdk/config`: `defineFilesConfig` and configuration types.
- `nuxt-files-sdk/nitro`: standalone Nitro setup and runtime registry.
- `nuxt-files-sdk/plugins`: native built-in Files SDK plugin exports.

Files SDK errors are preserved. Integration diagnostics use stable `nuxt-files-sdk:*` codes in their messages.
