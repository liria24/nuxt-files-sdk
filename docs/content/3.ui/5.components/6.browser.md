`FilesBrowser` treats common prefixes as folders and exposes the selected `StoredFile` through `v-model:selected`.

::note
The gateway must allow `list`. Thumbnails use `capabilities` and `url`; enabled row actions require their corresponding operations.
::

## Usage

::browser-example
::

```vue
<FilesBrowser v-model:selected="selected" :files="files" initial-prefix="documents/" />
```

### Header

Use the header slot to place controls that follow the current folder.

```vue
<FilesBrowser :files="files">
    <template #header="{ prefix, refresh }">
        <FilesDropzone :files="files" :prefix="prefix" @uploaded="refresh" />
    </template>
</FilesBrowser>
```

### Actions and thumbnails

```vue
<FilesBrowser :files="files" :actions="['download']" :thumbnails="false" />
```

## Examples

### Class prop

```vue
<FilesBrowser :files="files" class="max-w-4xl" />
```

### UI prop

```vue
<FilesBrowser :files="files" :ui="{ breadcrumb: 'sticky top-0', item: 'min-h-12' }" />
```

## API

### Props

| Prop            | Default        | Type                                                                                                                                                                                                         |
| --------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `files`         | required       | `FilesClient`                                                                                                                                                                                                |
| `selected`      | —              | `StoredFile \| undefined`                                                                                                                                                                                    |
| `initialPrefix` | `''`           | `string`                                                                                                                                                                                                     |
| `delimiter`     | `'/'`          | `string`                                                                                                                                                                                                     |
| `endpoint`      | `'/api/files'` | `string`                                                                                                                                                                                                     |
| `actions`       | all actions    | `Array<'download' \| 'copy' \| 'rename' \| 'move' \| 'delete'>`                                                                                                                                              |
| `readOnly`      | `false`        | `boolean`                                                                                                                                                                                                    |
| `thumbnails`    | `true`         | `boolean`                                                                                                                                                                                                    |
| `ui`            | —              | `{ root?: HTMLAttributes['class']; breadcrumb?: HTMLAttributes['class']; list?: HTMLAttributes['class']; item?: HTMLAttributes['class']; empty?: HTMLAttributes['class']; error?: HTMLAttributes['class'] }` |
| `class`         | —              | `HTMLAttributes['class']`                                                                                                                                                                                    |
| `home`          | —              | `FilesButtonOptions`                                                                                                                                                                                         |
| `breadcrumb`    | —              | `FilesButtonOptions`                                                                                                                                                                                         |
| `refresh`       | —              | `FilesButtonOptions`                                                                                                                                                                                         |
| `folder`        | —              | `FilesButtonOptions`                                                                                                                                                                                         |
| `file`          | —              | `FilesButtonOptions`                                                                                                                                                                                         |
| `loadMore`      | —              | `FilesButtonOptions`                                                                                                                                                                                         |
| `fileActions`   | —              | `FilesActionControls`                                                                                                                                                                                        |

### Slots

| Slot      | Type                                                               |
| --------- | ------------------------------------------------------------------ |
| `header`  | `{ prefix: string; refresh: (append?: boolean) => Promise<void> }` |
| `empty`   | `{}`                                                               |
| `content` | `{ items: StoredFile[]; prefixes: string[]; prefix: string }`      |

### Emits

| Event             | Type                              |
| ----------------- | --------------------------------- |
| `update:selected` | `[file: StoredFile \| undefined]` |
| `select`          | `[file: StoredFile]`              |
| `changed`         | `[]`                              |
| `error`           | `[error: Error]`                  |

The component exposes `refresh(): Promise<void>`.

## Theme

Use `app.config.ts` to set slot classes. Operation controls accept `label`, `icon`, `color`, `size`, `variant`, `loading`, `disabled`, `class`, and `ui` where applicable. See [Theming](/ui/theming) for control options and defaults.

```ts [app.config.ts]
export default defineAppConfig({
    ui: {
        filesBrowser: { slots: { root: 'my-files-root' } },
    },
})
```
