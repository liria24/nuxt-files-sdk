---
title: Search
description: Search files with substring, glob, regex, or exact matching.
---

`FilesSearch` supports four match modes, optional case-insensitive matching, and aborts the previous request before starting another.

::note
The gateway must allow `search` for the configured prefix. Server authorization still bounds every result.
::

## Usage

::search-example
::

```vue
<FilesSearch :files="files" prefix="documents/" @select="selected = $event" />
```

### Match mode

```vue
<FilesSearch :files="files" default-match="glob" :max-results="25" />
```

### Custom results

```vue
<FilesSearch :files="files">
    <template #content="{ results }">{{ results.length }} results</template>
</FilesSearch>
```

## Examples

### Class prop

```vue
<FilesSearch :files="files" class="max-w-2xl" />
```

```vue
<FilesSearch :files="files" :ui="{ list: 'max-h-80 overflow-auto', item: 'py-3' }" />
```

## API

### Props

| Prop              | Default       | Type                                                                                                                                  |
| ----------------- | ------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `files`           | required      | `FilesClient`                                                                                                                         |
| `prefix`          | `''`          | `string`                                                                                                                              |
| `defaultMatch`    | `'substring'` | `'substring' \| 'glob' \| 'regex' \| 'exact'`                                                                                         |
| `maxResults`      | `100`         | `number`                                                                                                                              |
| `ui`              | —             | `{ root?: HTMLAttributes['class']; list?: HTMLAttributes['class']; item?: HTMLAttributes['class']; error?: HTMLAttributes['class'] }` |
| `class`           | —             | `HTMLAttributes['class']`                                                                                                             |
| `query`           | —             | `FilesInputOptions`                                                                                                                   |
| `submit`          | —             | `FilesButtonOptions`                                                                                                                  |
| `match`           | —             | `FilesSelectOptions`                                                                                                                  |
| `caseInsensitive` | —             | `FilesCheckboxOptions`                                                                                                                |
| `result`          | —             | `FilesButtonOptions`                                                                                                                  |

### Slots

| Slot      | Type                        |
| --------- | --------------------------- |
| `content` | `{ results: StoredFile[] }` |

### Emits

| Event    | Type                 |
| -------- | -------------------- |
| `select` | `[file: StoredFile]` |
| `error`  | `[error: Error]`     |
