---
title: Upload Progress
description: Display per-file and aggregate upload progress.
---

`FilesUploadProgress` reads the live upload state exposed by `useFiles()` and renders nothing when no uploads are present.

::note
This component requires a `UseFilesReturn`, not a plain `FilesClient`, because progress and upload state are reactive composable fields.
::

## Usage

::upload-progress-example
::

```vue
<FilesUploadProgress :files="files" />
```

### Multiple files

When `uploads` contains more than one entry, the component adds an aggregate progress row automatically.

```ts
const files = useFiles()
await files.upload([
    { key: 'a.txt', body: fileA },
    { key: 'b.txt', body: fileB },
])
```

## Examples

### Class prop

```vue
<FilesUploadProgress :files="files" class="max-w-lg" />
```

### UI prop

```vue
<FilesUploadProgress :files="files" :ui="{ progress: 'h-1', row: 'gap-4' }" />
```

## API

### Props

| Prop      | Default     | Type                                                                                                                                                                     |
| --------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `files`   | required    | `UseFilesReturn`                                                                                                                                                         |
| `color`   | `'primary'` | `'error' \| 'info' \| 'neutral' \| 'primary' \| 'secondary' \| 'success' \| 'warning'`                                                                                   |
| `variant` | `'outline'` | `'ghost' \| 'outline' \| 'soft' \| 'solid' \| 'subtle'`                                                                                                                  |
| `size`    | `'md'`      | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                                                                                                   |
| `ui`      | —           | `{ root?: HTMLAttributes['class']; item?: HTMLAttributes['class']; row?: HTMLAttributes['class']; progress?: HTMLAttributes['class']; error?: HTMLAttributes['class'] }` |
| `class`   | —           | `HTMLAttributes['class']`                                                                                                                                                |

### Slots

This component does not provide slots.

### Emits

This component does not emit events.
