---
title: Dropzone
description: Validate and upload files or complete directory trees.
---

`FilesDropzone` validates accepted types, count, and size before uploading files sequentially. Directory uploads preserve relative keys.

::note
The gateway must allow `upload` for the target prefix. Client validation does not replace server-side authorization or upload limits.
::

## Usage

::dropzone-example
::

```vue
<FilesDropzone :files="files" prefix="uploads/" @uploaded="reload" />
```

### Accepted files

Use standard file-input accept syntax and apply count and byte limits before any upload starts.

```vue
<FilesDropzone :files="files" accept="image/*,.pdf" :max-files="10" :max-size="10_000_000" />
```

### Directories

```vue
<FilesDropzone :files="files" prefix="imports/" directory />
```

## Examples

### Class prop

```vue
<FilesDropzone :files="files" class="max-w-xl" />
```

### UI prop

```vue
<FilesDropzone :files="files" :ui="{ dropzone: 'min-h-64', status: 'font-medium' }" />
```

## API

### Props

| Prop        | Default                          | Type                                                                                                                                        |
| ----------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| `files`     | required                         | `FilesClient`                                                                                                                               |
| `accept`    | —                                | `string`                                                                                                                                    |
| `directory` | `false`                          | `boolean`                                                                                                                                   |
| `maxFiles`  | `1` (`Infinity` for directories) | `number`                                                                                                                                    |
| `maxSize`   | —                                | `number`                                                                                                                                    |
| `prefix`    | `''`                             | `string`                                                                                                                                    |
| `ui`        | —                                | `{ root?: HTMLAttributes['class']; dropzone?: HTMLAttributes['class']; error?: HTMLAttributes['class']; status?: HTMLAttributes['class'] }` |
| `class`     | —                                | `HTMLAttributes['class']`                                                                                                                   |
| `trigger`   | —                                | `FilesButtonOptions`                                                                                                                        |

### Slots

| Slot      | Type                     |
| --------- | ------------------------ |
| `content` | `{ uploading: boolean }` |
| `error`   | `{ error: Error }`       |

### Emits

| Event      | Type                       |
| ---------- | -------------------------- |
| `uploaded` | `[files: UploadOutcome[]]` |
| `error`    | `[error: Error]`           |

## Theme

Use `app.config.ts` to set slot classes. Operation controls accept `label`, `icon`, `color`, `size`, `variant`, `loading`, `disabled`, `class`, and `ui` where applicable. See [Theming](/ui/theming) for control options and defaults.

```ts [app.config.ts]
export default defineAppConfig({
    ui: {
        filesDropzone: { slots: { root: 'my-files-root' } },
    },
})
```
