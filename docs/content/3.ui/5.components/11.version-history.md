---
title: Version History
description: List and restore native Files SDK versions.
---

`FilesVersionHistory` shows native version records for one key and restores the selected version in place.

::note
The configured storage must use the Files SDK versioning plugin, and the gateway must allow `versions` and `restoreVersion`. Unsupported operations surface their native error.
::

## Usage

::version-history-example
::

```vue
<FilesVersionHistory file-key="documents/readme.txt" :files="files" @restored="reload" />
```

### Changing files

The list reloads automatically when `fileKey` changes.

```vue
<FilesVersionHistory :file-key="selected.key" :files="files" />
```

## Examples

### Class prop

```vue
<FilesVersionHistory file-key="documents/readme.txt" :files="files" class="max-w-xl" />
```

### UI prop

```vue
<FilesVersionHistory file-key="documents/readme.txt" :files="files" :ui="{ item: 'py-3' }" />
```

## API

### Props

| Prop      | Default  | Type                                                                                                                                                                   |
| --------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `files`   | required | `FilesClient`                                                                                                                                                          |
| `fileKey` | required | `string`                                                                                                                                                               |
| `ui`      | —        | `{ root?: HTMLAttributes['class']; list?: HTMLAttributes['class']; item?: HTMLAttributes['class']; empty?: HTMLAttributes['class']; error?: HTMLAttributes['class'] }` |
| `class`   | —        | `HTMLAttributes['class']`                                                                                                                                              |
| `restore` | —        | `FilesButtonOptions`                                                                                                                                                   |

### Slots

| Slot    | Type |
| ------- | ---- |
| `empty` | `{}` |

### Emits

| Event      | Type                     |
| ---------- | ------------------------ |
| `restored` | `[version: FileVersion]` |
| `error`    | `[error: Error]`         |

The component exposes `refresh(): Promise<void>`.
