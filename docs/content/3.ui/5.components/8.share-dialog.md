---
title: Share Dialog
description: Generate expiring download or upload URLs.
---

`FilesShareDialog` generates URLs with a configurable expiry and clamps the requested lifetime to the adapter's advertised maximum.

::note
Download mode uses `capabilities` and `url`. Upload mode uses `capabilities` and `signedUploadUrl`; the gateway must authorize the selected operation and key.
::

## Usage

::share-dialog-example
::

```vue
<FilesShareDialog file-key="documents/readme.txt" :files="files" @generated="share = $event" />
```

### Upload URL

```vue
<FilesShareDialog file-key="incoming/file.bin" :files="files" mode="upload" :default-expires-in="900" />
```

### Trigger

```vue
<FilesShareDialog file-key="documents/readme.txt" :files="files">
    <template #trigger="{ open }"><button @click="open">Share</button></template>
</FilesShareDialog>
```

## Examples

### Class prop

```vue
<FilesShareDialog file-key="documents/readme.txt" :files="files" class="inline-flex" />
```

### UI prop

```vue
<FilesShareDialog file-key="documents/readme.txt" :files="files" :ui="{ dialog: 'max-w-xl' }" />
```

## API

### Props

| Prop                | Default      | Type                                                                                                    |
| ------------------- | ------------ | ------------------------------------------------------------------------------------------------------- |
| `files`             | required     | `FilesClient`                                                                                           |
| `fileKey`           | required     | `string`                                                                                                |
| `mode`              | `'download'` | `'download' \| 'upload'`                                                                                |
| `defaultExpiresIn`  | `3600`       | `number`                                                                                                |
| `ui`                | —            | `{ root?: HTMLAttributes['class']; dialog?: HTMLAttributes['class']; error?: HTMLAttributes['class'] }` |
| `class`             | —            | `HTMLAttributes['class']`                                                                               |
| `trigger`           | —            | `FilesButtonOptions`                                                                                    |
| `expiryInput`       | —            | `FilesInputOptions`                                                                                     |
| `dispositionSelect` | —            | `FilesSelectOptions`                                                                                    |
| `urlInput`          | —            | `FilesInputOptions`                                                                                     |
| `copy`              | —            | `FilesButtonOptions`                                                                                    |
| `cancel`            | —            | `FilesButtonOptions`                                                                                    |
| `submit`            | —            | `FilesButtonOptions`                                                                                    |

### Slots

| Slot      | Type                            |
| --------- | ------------------------------- |
| `trigger` | `{ open: () => Promise<void> }` |

### Emits

| Event       | Type             |
| ----------- | ---------------- |
| `generated` | `[url: string]`  |
| `error`     | `[error: Error]` |

## Theme

```ts [app.config.ts]
export default defineAppConfig({
    ui: {
        filesShareDialog: { slots: { root: 'my-files-root' } },
    },
})
```
