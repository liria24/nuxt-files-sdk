---
title: Multipart Uploader
description: Upload a local file queue with bounded concurrency.
---

`FilesMultipartUploader` owns a local `File[]` queue through `v-model`, limits parallel work, and exposes cancellation and retry-friendly state.

::note
The gateway must allow `upload`. The `files` prop remains the `UseFilesReturn` returned by `useFiles()`; `v-model` is the local file queue.
::

## Usage

::multipart-uploader-example
::

```vue
<FilesMultipartUploader v-model="uploads" :files="files" prefix="uploads/" />
```

### Concurrency

```vue
<FilesMultipartUploader v-model="uploads" :files="files" :concurrency="2" />
```

### Accepted files

```vue
<FilesMultipartUploader v-model="uploads" :files="files" accept="image/*,.pdf" />
```

## Examples

### Class prop

```vue
<FilesMultipartUploader v-model="uploads" :files="files" class="max-w-2xl" />
```

### UI prop

```vue
<FilesMultipartUploader v-model="uploads" :files="files" :ui="{ item: 'rounded-md bg-muted p-3' }" />
```

## API

### Props

| Prop          | Default  | Type                                                                                                                                  |
| ------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `files`       | required | `UseFilesReturn`                                                                                                                      |
| `modelValue`  | `[]`     | `File[]`                                                                                                                              |
| `accept`      | —        | `string`                                                                                                                              |
| `concurrency` | `3`      | `number`                                                                                                                              |
| `prefix`      | `''`     | `string`                                                                                                                              |
| `ui`          | —        | `{ root?: HTMLAttributes['class']; list?: HTMLAttributes['class']; item?: HTMLAttributes['class']; error?: HTMLAttributes['class'] }` |
| `class`       | —        | `HTMLAttributes['class']`                                                                                                             |
| `choose`      | —        | `FilesButtonOptions`                                                                                                                  |
| `upload`      | —        | `FilesButtonOptions`                                                                                                                  |
| `cancel`      | —        | `FilesButtonOptions`                                                                                                                  |

### Slots

This component does not provide slots.

### Emits

| Event               | Type                       |
| ------------------- | -------------------------- |
| `update:modelValue` | `[files: File[]]`          |
| `uploaded`          | `[files: UploadOutcome[]]` |
| `error`             | `[error: Error]`           |
