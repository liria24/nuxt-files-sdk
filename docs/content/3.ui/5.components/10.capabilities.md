---
title: Capabilities
description: Display the operations supported by the selected adapter.
---

`FilesCapabilities` renders the gateway's native adapter capability result, including delimiter listing, signed URLs, and multipart support.

::note
The gateway must allow `capabilities`. The component reports the native error when capability discovery fails.
::

## Usage

::capabilities-example
::

```vue
<FilesCapabilities :files="files" />
```

### Supported only

```vue
<FilesCapabilities :files="files" supported-only />
```

## Examples

### Class prop

```vue
<FilesCapabilities :files="files" class="max-w-lg" />
```

### UI prop

```vue
<FilesCapabilities :files="files" :ui="{ list: 'grid grid-cols-2', item: 'gap-3' }" />
```

## API

### Props

| Prop            | Default     | Type                                                                                                                                  |
| --------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `files`         | required    | `FilesClient`                                                                                                                         |
| `supportedOnly` | `false`     | `boolean`                                                                                                                             |
| `color`         | `'primary'` | `'error' \| 'info' \| 'neutral' \| 'primary' \| 'secondary' \| 'success' \| 'warning'`                                                |
| `variant`       | `'outline'` | `'ghost' \| 'outline' \| 'soft' \| 'solid' \| 'subtle'`                                                                               |
| `size`          | `'md'`      | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                                                                |
| `ui`            | —           | `{ root?: HTMLAttributes['class']; list?: HTMLAttributes['class']; item?: HTMLAttributes['class']; error?: HTMLAttributes['class'] }` |
| `class`         | —           | `HTMLAttributes['class']`                                                                                                             |

### Slots

This component does not provide slots.

### Emits

| Event   | Type             |
| ------- | ---------------- |
| `error` | `[error: Error]` |
