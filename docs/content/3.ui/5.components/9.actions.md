---
title: Actions
description: Download, copy, rename, move, or delete a file.
---

`FilesActions` presents only the allowed file operations and emits `changed` after a mutating action succeeds.

::note
Each visible action must be allowed by the gateway. Hiding an action is a UI restriction, not an authorization boundary.
::

## Usage

::actions-example
::

```vue
<FilesActions file-key="documents/readme.txt" :files="files" @changed="reload" />
```

### Allowed actions

```vue
<FilesActions file-key="documents/readme.txt" :files="files" :actions="['download', 'delete']" />
```

### Trigger

```vue
<FilesActions file-key="documents/readme.txt" :files="files">
    <template #trigger>Manage</template>
</FilesActions>
```

## Examples

### Class prop

```vue
<FilesActions file-key="documents/readme.txt" :files="files" class="ml-auto" />
```

### UI prop

```vue
<FilesActions file-key="documents/readme.txt" :files="files" :ui="{ menu: 'min-w-48', dialog: 'max-w-md' }" />
```

## API

### Props

| Prop      | Default     | Type                                                                                                                                                                       |
| --------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `files`   | required    | `FilesClient`                                                                                                                                                              |
| `fileKey` | required    | `string`                                                                                                                                                                   |
| `actions` | all actions | `Array<'download' \| 'copy' \| 'rename' \| 'move' \| 'delete'>`                                                                                                            |
| `color`   | `'primary'` | `'error' \| 'info' \| 'neutral' \| 'primary' \| 'secondary' \| 'success' \| 'warning'`                                                                                     |
| `variant` | `'ghost'`   | `'ghost' \| 'outline' \| 'soft' \| 'solid' \| 'subtle'`                                                                                                                    |
| `size`    | `'md'`      | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                                                                                                     |
| `ui`      | —           | `{ root?: HTMLAttributes['class']; trigger?: HTMLAttributes['class']; menu?: HTMLAttributes['class']; dialog?: HTMLAttributes['class']; error?: HTMLAttributes['class'] }` |
| `class`   | —           | `HTMLAttributes['class']`                                                                                                                                                  |

### Slots

| Slot      | Type |
| --------- | ---- |
| `trigger` | `{}` |

### Emits

| Event     | Type             |
| --------- | ---------------- |
| `changed` | `[]`             |
| `error`   | `[error: Error]` |
