---
title: Trash Bin
description: Restore or permanently purge soft-deleted files.
---

`FilesTrashBin` lists soft-deleted entries, restores individual files, and can purge one item or empty the trash after confirmation.

::note
The configured storage must use the Files SDK soft-delete plugin, and the gateway must allow `trashed`, `restoreTrashed`, and `purge`. Purge is permanent.
::

## Usage

::trash-bin-example
::

```vue
<FilesTrashBin :files="files" @restored="reload" />
```

### Refreshing

Use the exposed method after another part of the page moves an item to trash.

```vue
<FilesTrashBin ref="trash" :files="files" />
```

```ts
await trash.value?.refresh()
```

## Examples

### Class prop

```vue
<FilesTrashBin :files="files" class="max-w-2xl" />
```

### UI prop

```vue
<FilesTrashBin :files="files" :ui="{ list: 'divide-y divide-default', item: 'py-3' }" />
```

## API

### Props

| Prop      | Default     | Type                                                                                                                                                                   |
| --------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `files`   | required    | `FilesClient`                                                                                                                                                          |
| `color`   | `'primary'` | `'error' \| 'info' \| 'neutral' \| 'primary' \| 'secondary' \| 'success' \| 'warning'`                                                                                 |
| `variant` | `'outline'` | `'ghost' \| 'outline' \| 'soft' \| 'solid' \| 'subtle'`                                                                                                                |
| `size`    | `'md'`      | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                                                                                                 |
| `ui`      | —           | `{ root?: HTMLAttributes['class']; list?: HTMLAttributes['class']; item?: HTMLAttributes['class']; empty?: HTMLAttributes['class']; error?: HTMLAttributes['class'] }` |
| `class`   | —           | `HTMLAttributes['class']`                                                                                                                                              |

### Slots

| Slot    | Type |
| ------- | ---- |
| `empty` | `{}` |

### Emits

| Event      | Type                  |
| ---------- | --------------------- |
| `restored` | `[file: TrashedFile]` |
| `changed`  | `[]`                  |
| `error`    | `[error: Error]`      |

The component exposes `refresh(): Promise<void>`.
