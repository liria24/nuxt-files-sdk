---
title: Preview
description: Preview images, text, JSON, and PDF files.
---

`FilesPreview` chooses a preview from file metadata, loads text and JSON directly, and releases PDF object URLs when the file changes or the component unmounts.

::note
The gateway must allow `head` and `download`. Image previews also use `capabilities` and `url` when signed URLs are available.
::

## Usage

::preview-example
::

```vue
<FilesPreview file="documents/readme.txt" :files="files" />
```

### Stored file

Pass a `StoredFile` to skip the metadata request.

```vue
<FilesPreview :file="selected" :files="files" />
```

### Custom preview

```vue
<FilesPreview :file="selected" :files="files">
    <template #preview="{ kind, text }">
        <article v-if="kind === 'text'">{{ text }}</article>
    </template>
</FilesPreview>
```

## API

### Props

| Prop       | Default        | Type                                                                                                                                     |
| ---------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `files`    | required       | `FilesClient`                                                                                                                            |
| `file`     | required       | `StoredFile \| string`                                                                                                                   |
| `endpoint` | `'/api/files'` | `string`                                                                                                                                 |
| `ui`       | —              | `{ root?: HTMLAttributes['class']; body?: HTMLAttributes['class']; caption?: HTMLAttributes['class']; error?: HTMLAttributes['class'] }` |
| `class`    | —              | `HTMLAttributes['class']`                                                                                                                |

### Slots

| Slot      | Type                                                                                                             |
| --------- | ---------------------------------------------------------------------------------------------------------------- |
| `preview` | `{ file: StoredFile \| undefined; kind: 'image' \| 'pdf' \| 'text' \| 'unknown'; source: string; text: string }` |
| `error`   | `{ error: Error }`                                                                                               |

### Emits

| Event   | Type             |
| ------- | ---------------- |
| `error` | `[error: Error]` |
