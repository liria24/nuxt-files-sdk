---
title: List
description: List files with metadata, thumbnails, selection, and actions.
---

`FilesList` renders one prefix, supports cursor loading, and emits the selected file.

::note
The gateway must allow `list`. Thumbnails also use `capabilities` and `url`; enabled actions require their corresponding gateway operations.
::

## Usage

::list-example
::

```vue
<FilesList :files="files" prefix="documents/" @select="selected = $event" />
```

### Actions

```vue
<FilesList :files="files" :actions="['download', 'delete']" />
<FilesList :files="files" read-only />
```

### Thumbnails

```vue
<FilesList :files="files" :thumbnails="false" />
```

## Examples

### Class prop

```vue
<FilesList :files="files" class="max-h-96 overflow-auto" />
```

### UI prop

```vue
<FilesList :files="files" :ui="{ list: 'divide-y divide-default', item: 'py-3' }" />
```

## API

### Props

| Prop         | Default        | Type                                                                                                                                                                   |
| ------------ | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `files`      | required       | `FilesClient`                                                                                                                                                          |
| `prefix`     | `''`           | `string`                                                                                                                                                               |
| `endpoint`   | `'/api/files'` | `string`                                                                                                                                                               |
| `actions`    | all actions    | `Array<'download' \| 'copy' \| 'rename' \| 'move' \| 'delete'>`                                                                                                        |
| `readOnly`   | `false`        | `boolean`                                                                                                                                                              |
| `thumbnails` | `true`         | `boolean`                                                                                                                                                              |
| `color`      | `'primary'`    | `'error' \| 'info' \| 'neutral' \| 'primary' \| 'secondary' \| 'success' \| 'warning'`                                                                                 |
| `variant`    | `'outline'`    | `'ghost' \| 'outline' \| 'soft' \| 'solid' \| 'subtle'`                                                                                                                |
| `size`       | `'md'`         | `'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl'`                                                                                                                                 |
| `ui`         | —              | `{ root?: HTMLAttributes['class']; list?: HTMLAttributes['class']; item?: HTMLAttributes['class']; empty?: HTMLAttributes['class']; error?: HTMLAttributes['class'] }` |
| `class`      | —              | `HTMLAttributes['class']`                                                                                                                                              |

### Slots

| Slot      | Type                                                   |
| --------- | ------------------------------------------------------ |
| `empty`   | `{}`                                                   |
| `content` | `{ items: StoredFile[]; reload: () => Promise<void> }` |

### Emits

| Event     | Type                 |
| --------- | -------------------- |
| `select`  | `[file: StoredFile]` |
| `changed` | `[]`                 |
| `error`   | `[error: Error]`     |
