title: Overview
description: Twelve Files SDK components for upload, browsing, preview, sharing, versioning, and trash.
---

Nuxt Files SDK registers twelve Vue components by default. No additional package installation or module configuration is required.

These components are independent Vue ports based on the MIT-licensed [Files SDK UI](https://files-sdk.dev/docs/ui), adapted to Nuxt conventions while retaining the upstream behavior. This is an unofficial project and is not affiliated with, endorsed by, or maintained by Files SDK or its maintainers.

The UI covers uploads, lists, progress, multipart queues, previews, folder browsing, search, sharing, file actions, capability discovery, version history, and soft-delete trash. Start with [Theming](/ui/theming), or browse the [component reference](/ui/components/dropzone).

Every component accepts `color`, `variant`, `size`, `ui`, and `class`. Gateway errors retain their native Files SDK identity and are also emitted through `error`.

::note
The components only call operations allowed by your Files gateway. Keep authorization and key-prefix checks on the server; rendering a read-only UI is not an authorization boundary.
::
