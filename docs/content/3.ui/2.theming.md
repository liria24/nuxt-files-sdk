---
title: Theming
description: Customize Files components through app.config.ts, common props, slots, and Tailwind CSS.
---

Themes are configured under `ui` in `app.config.ts`. Shared icon names live under `ui.files.icons`; each component has its own key such as `ui.filesDropzone` or `ui.filesBrowser`.

```ts [app.config.ts]
export default defineAppConfig({
    ui: {
        files: {
            icons: { upload: 'i-lucide-cloud-upload' },
        },
        filesDropzone: {
            slots: { root: 'my-dropzone', error: 'my-error' },
            variants: {
                size: { sm: { root: 'text-sm' } },
            },
            compoundVariants: [{ color: 'primary', variant: 'outline', class: { root: 'my-primary-outline' } }],
            defaultVariants: { size: 'sm' },
        },
    },
})
```

Resolution order is built-in theme, `app.config.ts`, the `color`/`variant`/`size` props, the component `ui` prop, then root `class`.

```vue
<FilesDropzone
    :files="files"
    color="secondary"
    size="lg"
    variant="soft"
    :ui="{ dropzone: 'min-h-80' }"
    class="my-files-root"
/>
```

The stylesheet uses `--ui-primary`, `--ui-bg`, `--ui-border`, and `--ui-text` when supplied, with built-in fallback values. Tailwind utility classes can be used in `slots`, `variants`, `ui`, and `class`.
