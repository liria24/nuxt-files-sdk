---
title: Theming
description: Customize Files components through app.config.ts, common props, slots, and Tailwind CSS.
---

Themes are configured under `ui` in `app.config.ts`. Shared icon names live under `ui.files.icons`; each component has its own key such as `ui.filesDropzone` or `ui.filesBrowser`.

```ts [app.config.ts]
export default defineAppConfig({
    ui: {
        files: {
            icons: { upload: 'i-lucide-cloud-upload' },
        },
        filesDropzone: {
            slots: { root: 'my-dropzone', error: 'my-error' },
        },
    },
})
```

Resolution order for Files slots is the built-in theme, `app.config.ts`, the component `ui` prop, then root `class`. Style each internal operation through its named prop. The controls support `label`, `icon`, `color`, `size`, `variant`, `loading`, `disabled`, `class`, and `ui` where applicable. They do not accept navigation targets or event handlers; Files SDK operations remain owned by the Files component.

```vue
<FilesDropzone
    :files="files"
    :trigger="{ color: 'secondary', size: 'lg', variant: 'soft' }"
    :ui="{ dropzone: 'min-h-80' }"
    class="my-files-root"
/>
```

With Nuxt UI installed, the internal controls use its UButton, UInput, USelect, UCheckbox, and UProgress. Independently, they use local styles and Reka primitives for select, checkbox, and progress. The stylesheet uses `--ui-primary`, `--ui-bg`, `--ui-border`, and `--ui-text` when supplied, with built-in fallback values. Tailwind utility classes can be used in `slots`, `ui`, and `class`.
