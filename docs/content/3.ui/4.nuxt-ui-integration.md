---
title: Nuxt UI Integration
description: Use Files components with UApp, UTheme, and Nuxt UI component detection.
---

In an application that already uses Nuxt UI, list both modules. No additional Files UI setup is required.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ['@nuxt/ui', 'nuxt-files-sdk'],
})
```

## UApp locale

Files components react to the locale supplied by `<UApp :locale>`. An ordinary English Nuxt UI locale works without modification because Files messages fall back to the bundled English locale. Merge `messages.files` only when you want to replace or translate those messages.

```vue [app/app.vue]
<script setup lang="ts">
import { en } from '@nuxt/ui/locale'
import { withFilesLocale } from 'nuxt-files-sdk/ui/locale'

const locale = withFilesLocale(en)
</script>

<template>
    <UApp :locale="locale">
        <NuxtPage />
    </UApp>
</template>
```

For applications using namespace imports, prepare every locale once and select it with your i18n state:

```vue [app/app.vue]
<script setup lang="ts">
import * as uiLocales from '@nuxt/ui/locale'
import { withFilesLocales } from 'nuxt-files-sdk/ui/locale'

const locales = withFilesLocales(uiLocales)
const { locale } = useI18n()
</script>

<template>
    <UApp :locale="locales[locale]">
        <NuxtPage />
    </UApp>
</template>
```

## UTheme

`<UTheme>` can scope Files prop defaults and slot classes. Explicit component props win over the nearest theme, followed by `app.config.ts` defaults and component defaults, matching Nuxt UI.

```vue
<UTheme
    :props="{ filesDropzone: { trigger: { color: 'secondary', size: 'lg', variant: 'soft' } } }"
    :ui="{ filesDropzone: { root: 'ring-2 ring-secondary', dropzone: 'min-h-80' } }"
>
    <FilesDropzone :files="files" />
</UTheme>
```

Nested themes merge with their parent. A prop passed directly to `FilesDropzone` or a class supplied through its `ui` prop takes precedence over the scoped value.

## Component detection

Nuxt UI's `experimental.componentDetection` can remain enabled:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    ui: {
        experimental: { componentDetection: true },
    },
})
```

No additional Files configuration is required when component detection is enabled.
