---
title: I18n
description: Use the bundled English Files messages and locale types.
---

Files components include English messages and use them automatically. The locale `code` controls dates and numbers, while `dir` is applied to each component root.

The public locale entrypoint exports `en`, `FilesLocale`, `FilesMessages`, `withFilesLocale`, and `withFilesLocales`:

```ts
import { en as filesEn } from 'nuxt-files-sdk/ui/locale'

console.log(filesEn.code) // en
```

`withFilesLocale` preserves the selected locale's `code`, `dir`, and existing messages while adding `messages.files` without changing the original object.

```ts
import { en } from '@nuxt/ui/locale'
import { withFilesLocale } from 'nuxt-files-sdk/ui/locale'

const locale = withFilesLocale(en)
```

Use `withFilesLocales` when your application imports the Nuxt UI locale namespace. Its keys remain intact, so the current locale can be selected directly.

```ts
import * as uiLocales from '@nuxt/ui/locale'
import { withFilesLocales } from 'nuxt-files-sdk/ui/locale'

const locales = withFilesLocales(uiLocales)
```

Files messages currently fall back to English for every locale. To pass the result to `<UApp>`, see [Nuxt UI Integration](/ui/nuxt-ui-integration).
