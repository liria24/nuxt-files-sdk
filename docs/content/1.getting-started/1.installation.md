---
title: Installation
description: Register the module, configure local storage, and complete the first upload and download.
---

This path uses the filesystem adapter, so the first request needs no cloud account or credentials.

## Install and register the module

::code-group

```bash [npm]
npm install nuxt-files-sdk
```

```bash [pnpm]
pnpm add nuxt-files-sdk
```

```bash [bun]
bun add nuxt-files-sdk
```

```bash [yarn]
yarn add nuxt-files-sdk
```

::

`files-sdk` is a required peer dependency. Bun and npm 7+ install it automatically, so the commands above remain sufficient. If peer installation is disabled in your package manager, install both packages explicitly:

```bash [Terminal]
bun add nuxt-files-sdk files-sdk
```

Add the Nuxt module.
Next, create `files.config.ts` to set up your storage configuration.
Finally, build a minimal API.

::code-tree{defaultValue="nuxt.config.ts", expandAll=true}

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ['nuxt-files-sdk'],
})
```

```ts [files.config.ts]
export default defineFilesConfig({
    storage: {
        adapter: 'fs',
        config: { root: '.data/files' },
    },
})
```

```ts [server/api/hello.get.ts]
export default defineEventHandler(async () => {
    const files = useServerFiles()

    await files.upload('hello.txt', 'Hello from Nuxt')
    const file = await files.download('hello.txt')

    return {
        key: file.key,
        text: await file.text(),
    }
})
```

::

## Move beyond local storage

Replace `fs` with the provider your deployment supports, install that provider's optional peer dependencies, and follow its setup page in the [Files SDK provider reference](https://files-sdk.dev/docs/providers).
Keep a local override with [Development Storage](/usage/development-storage) when production credentials should not be required on a developer machine.
