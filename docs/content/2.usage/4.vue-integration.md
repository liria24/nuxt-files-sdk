---
title: Vue Integration
description: Connect the auto-imported Files SDK Vue composables to an authorized Nitro gateway.
---

The module auto-imports `useFiles`, `useFile`, `useList`, and `useSearch` from `files-sdk/vue`. These browser composables speak to an HTTP gateway; they do not call `useServerFiles()` directly.

## Mount a gateway

Create a Nitro route and pass it the server client. The smallest safe example below exposes read operations only:

```ts [server/api/files.ts]
import { createFilesRouter } from 'files-sdk/api'
import { createRouteHandler } from 'files-sdk/nitro'

const router = createFilesRouter({
    files: () => useServerFiles(),
    operations: ['capabilities', 'list', 'head', 'download'],
})

export default defineEventHandler(createRouteHandler(router))
```

`createFilesRouter` denies operations by default. For uploads or deletes, add only the required operations and an `authorize` hook that applies your application's identity and key-prefix rules. The [authorization guide](https://files-sdk.dev/docs/ui/server/authorization) is the source of truth for that boundary.

## Read from a component

```vue [app/pages/files.vue]
<script setup lang="ts">
const prefix = ref('public/')
const list = useList(() => ({ prefix: prefix.value }), {
    endpoint: '/api/files',
})
const selectedKey = ref<string>()
const file = useFile(selectedKey, { endpoint: '/api/files' })
const search = useSearch('*.pdf', {}, { endpoint: '/api/files' })
</script>

<template>
    <p v-if="list.isLoading">Loading files…</p>
    <ul v-else>
        <li v-for="item in list.data?.items" :key="item.key">
            <button type="button" @click="selectedKey = item.key">
                {{ item.key }}
            </button>
        </li>
    </ul>
    <p v-if="file.data">{{ file.data.key }}</p>
    <p>{{ search.data?.length ?? 0 }} PDF files</p>
</template>
```

Inputs may be refs or getters, so reads rerun when `prefix`, the selected key, or a search pattern changes. Each query returns `data`, `error`, `isLoading`, `isFetching`, and `refetch` refs.

Use `useFiles({ endpoint: '/api/files' })` for imperative uploads, downloads, and mutations plus upload progress and error state. The complete composable API lives in the [Files SDK Vue guide](https://files-sdk.dev/docs/ui/client/vue).
