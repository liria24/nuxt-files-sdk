Configure module options under `files` in `nuxt.config.ts`.

## `config`

**Type:** `string`
**Default:** `'files.config.ts'`

Path to the Files configuration module, relative to the Nuxt root directory.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ['nuxt-files-sdk'],
    files: { config: 'config/storage.ts' },
})
```

## `devtools`

**Type:** `boolean | { write?: boolean }`
**Default:** `true`

Enables the Nuxt Files SDK DevTools tab while Nuxt is in development and Nuxt DevTools itself is enabled. File writes are enabled by default. Set `write: false` when the development browser should be read-only.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ['nuxt-files-sdk'],
    devtools: { enabled: true },
    files: { devtools: { write: false } },
})
```

`devtools: false` disables the integration. The tab and its internal endpoints are never installed in a production build, regardless of this option.
