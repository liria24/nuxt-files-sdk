---
title: Module Options
description: Configure the Files config path and DevTools behavior in Nuxt.
---

Configure module options under `files` in `nuxt.config.ts`.

## `config`

**Type:** `string`
**Default:** `'files.config.ts'`

Path to the Files configuration module, relative to the Nuxt root directory.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ['nuxt-files-sdk'],
    files: { config: 'config/storage.ts' },
})
```

## `devtools`

**Type:** `boolean | { write?: boolean }`
**Default:** `true`

Enables the Files tab during development. Authenticated Nuxt DevTools users can upload and delete files by default. Set `write: false` for read-only access.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ['nuxt-files-sdk'],
    devtools: { enabled: true },
    files: { devtools: { write: false } },
})
```

`devtools: false` disables the Files tab. It is available only during development.
