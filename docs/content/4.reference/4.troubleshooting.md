---
title: Troubleshooting
description: Resolve configuration, generated type, provider, DevTools, and deployment problems.
---

## The registry is not configured

Confirm that `nuxt-files-sdk` is in `modules`, `files.config.ts` exists at the configured path, and the code runs inside Nitro server context. Standalone Nitro must install `nuxt-files-sdk/nitro` and import `useServerFiles` from `nuxt-files-sdk/runtime`.

## A storage name is rejected

Single storage uses `useServerFiles()` with no argument. Named storage always uses `useServerFiles('name')`. Run `nuxt prepare` or `nuxt typecheck` after changing names so generated declarations are current.

## A provider cannot be constructed

Check the provider's required options, environment variables, optional packages, and runtime support in the [Files SDK provider reference](https://files-sdk.dev/docs/providers). Configuration resolvers must return synchronously. The module preserves the native error and does not fall back to another provider.

## Types are missing

Run the application's native preparation step before a standalone TypeScript invocation:

```bash [Terminal]
bunx nuxt prepare
bunx nuxt typecheck
```

For standalone Nitro, use `nitro prepare` and `nitro typecheck`. Do not hand-edit declarations under `.nuxt` or `.nitro`.

## The Files tab is missing

Use `nuxt dev`, enable Nuxt DevTools, and make sure `files.devtools` is not `false`. The tab is intentionally unavailable in preview and production servers.

## Browser operations return forbidden

Vue composables require an application-owned Files SDK gateway. The router denies operations by default; enable the required operation and supply authorization. See [Vue Integration](/usage/vue-integration) and the [Files SDK authorization guide](https://files-sdk.dev/docs/ui/server/authorization).

## Local files disappear after deployment

The deployment probably has an ephemeral filesystem. Choose persistent storage supported by that environment; `fs` and `memory` are useful local defaults, not universal production stores.
