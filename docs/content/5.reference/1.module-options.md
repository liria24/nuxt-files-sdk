title: Module Options
description: Nuxt module options, defaults, effects, and minimal configurations.
---

Configure module options under `files` in `nuxt.config.ts`.

## `config`

**Type:** `string`
**Default:** `'files.config.ts'`

Path to the Files configuration module, relative to the Nuxt root directory.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ['nuxt-files-sdk'],
    files: { config: 'config/storage.ts' },
})
```

## `devtools`

**Type:** `boolean | { write?: boolean }`
**Default:** `true`

Enables the Files tab during development. Authenticated Nuxt DevTools users can upload and delete files by default. Set `write: false` for read-only access.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ['nuxt-files-sdk'],
    devtools: { enabled: true },
    files: { devtools: { write: false } },
})
```

`devtools: false` disables the integration. The tab and its internal endpoints are never installed in a production build, regardless of this option.

## `ui`

**Type:** `boolean`
**Default:** `true`

Registers the Files Vue components, stylesheet, and app-config defaults. Set it to `false` when the application only uses server APIs or native Files SDK composables.

```ts [nuxt.config.ts]
export default defineNuxtConfig({
    modules: ['nuxt-files-sdk'],
    files: { ui: false },
})
```
