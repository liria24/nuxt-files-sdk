---
title: Upgrade to v0.3
description: Update Node, file metadata access, and bulk result fields for Files SDK v3.
---

v0.3 upgrades the owned Files SDK from 2.6.2 to 3.0.0. Apply these changes where your application uses the affected APIs.

## Update Node and the module

Use **Node.js 22.12.0 or newer**, then update the module:

::code-group

```bash [npm]
npm install nuxt-files-sdk@^0.3.0
```

```bash [pnpm]
pnpm add nuxt-files-sdk@^0.3.0
```

```bash [bun]
bun add nuxt-files-sdk@^0.3.0
```

```bash [yarn]
yarn add nuxt-files-sdk@^0.3.0
```

::

Regenerate Nuxt types:

```bash
npx nuxt prepare
```

Standalone Nitro apps should rerun their existing [type generation](/advanced/nitro-module). Keep imports through `#files-sdk` and its public subpaths; no separate Files SDK installation is needed.

## Read metadata as FileInfo

`head()`, `list().items`, `listAll()`, and `search()` return metadata without body methods. Read bytes with `download()`:

::code-group

```ts [v0.2]
import type { StoredFile } from '#files-sdk'

const files = useServerFiles()
const file: StoredFile = await files.head('notes.txt')
console.log(file.name, file.type)
const text = await file.text()
```

```ts [v0.3]
import type { FileInfo } from '#files-sdk'

const files = useServerFiles()
const file: FileInfo = await files.head('notes.txt')
console.log(file.key, file.contentType)
const text = await (await files.download(file.key)).text()
```

::

Browser client upload results also use `contentType`:

::code-group

```ts [v0.2 browser]
const uploaded = await client.upload(file)
const contentType = uploaded.type
```

```ts [v0.3 browser]
const uploaded = await client.upload(file)
const contentType = uploaded.contentType
```

::

Browser `File.type` and downloaded `StoredFile.type` remain valid. Server `upload()` results already used `contentType` in v0.2.

## Read bulk successes from results

::code-group

```ts [v0.2]
const { files: items, errors } = await useServerFiles().head(['a.txt', 'b.txt'])
```

```ts [v0.3]
const { results: items, errors } = await useServerFiles().head(['a.txt', 'b.txt'])
```

::

For array calls, rename `upload().uploaded`, `download().downloaded`, `head().files`, and `delete().deleted` to `results`. Per-key `errors` remain; `exists([...])` keeps `existing`, `missing`, and `errors`.

Upgrade browser clients and Gateways together: v2 and v3 wire formats are incompatible. `#files-sdk/client` selects the module's owned version.

For conditional changes to errors, URL expiry, `fs.defaultUrlExpiresIn`, custom adapters, or plugins, see the [upstream v3 migration notes](https://github.com/haydenbleasel/files-sdk/blob/76196b9d43ca016a7f339719a68e76ae80441c0e/packages/files-sdk/CHANGELOG.md#300). Keep optional provider SDKs required by your configured client.
